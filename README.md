# Suite de Tableros Analíticos CADIT

Tableros web interactivos para consulta y seguimiento de fuentes de información externa.

## Tableros incluidos
- **SNIES · Base Externa:** `index.html`
- **Registro y Avance de Fuentes:** `fuentes.html`
- **ICETEX · Créditos:** `icetex.html`
- **SENA · Formación:** `sena.html`
- **Servicio Público de Empleo:** `servicioempleo.html`
- **Educación Superior · LATAM:** `latam.html`
- **MinCiencias · Grupos:** `minciencias.html`
- **IDIC · Innovación:** `idic.html`
- **RUES · Empresas:** `rues.html`

## Cómo ejecutar localmente
1. Clona el repositorio:
   ```bash
   git clone https://github.com/NorbeyTovar/dashboards.git
   cd dashboards
   ```
2. Inicia un servidor web local:
   ```bash
   python -m http.server 8000
   ```
3. Abre en tu navegador:
   `http://localhost:8000/index.html` o `http://localhost:8000/fuentes.html`
